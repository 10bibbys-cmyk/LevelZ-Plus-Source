# Third-party attribution and source rights

**LevelZ+** is an independent compatibility expansion for **LevelZ** on Minecraft 1.20.1 Fabric. It is not an official component of LevelZ or the optional mods it integrates with.

## Core dependency
- [LevelZ](https://modrinth.com/mod/levelz) — required, tested against version **1.4.13**
- [Fabric](https://fabricmc.net/) — loader and API for Minecraft 1.20.1

## Optional integrations
LevelZ+ contains interoperability code for optional mods including Tom's Simple Storage, Better Combat, Spell Engine, Small Ships, Stamina Attributes, RPG Mana, Combat Roll, Zenith Attributes, Diet, Passive Regen, Actually Harvest, Bountiful, Numismatic Overhaul, XP Storage, JobsAddon, Farmer's Delight, Tide, Runic Attunement, Felled and Zarith.
